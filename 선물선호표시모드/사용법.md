# 선물·화제 취향 표시 0.4.0

선물 선택 목록에서 상대가 좋아하는 아이템의 이름·대분류·소분류를 분홍색으로 표시합니다. 화제는 현재 상대에게 효과 배율이 1보다 큰 항목을 같은 색으로 표시합니다. 검색·정렬·스크롤·대상 변경을 반영합니다.

금란선옥의 아이템·효과·상점 처리는 포함하지 않습니다. 독박육아·금란선옥과 각각 별도로 작동합니다. 표시에는 DLL이 필요하며 창작마당 구독만으로 실행되는 모드가 아닙니다. 추천 탭·O 표시·추가 정렬 열은 만들지 않았습니다. 기존 선택창의 열과 정렬은 게임이 처리합니다.

게임 종료 후 분리배포/선물화제취향표시_v0.4.0/설치.cmd를 실행하세요. 기존 0.2~0.3 통합판 사용자는 분리배포/선물화제_금란선옥_분리설치/설치.cmd로 먼저 이전하세요. 두 모드가 분리 설치되고 기존 통합 데이터는 백업 후 정리됩니다.

설치 위치는 게임 폴더의 LOH_GiftHighlight/ 및 version.dll입니다. 표시 모드에는 별도 데이터 모드 선택이 필요 없습니다. 로그는 LOH_GiftHighlight/LOH_GiftHighlight.log, 정상 연결 표시는 READY 0.4.0과 topic rules: READY입니다.

분리 묶음에서 제거.cmd -Target Gift를 실행하면 표시만 제거합니다. 금란선옥이 남아 있으면 공용 입구는 유지됩니다.

빌드: Python으로 이 폴더의 build.py 실행. 게임 메타데이터 연결 검사 및 20개 선호 분류 검사 통과. 분리판의 실제 게임 화면 확인은 아직 남아 있습니다.
