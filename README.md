# 선물·화제 취향 표시 (영웅입지전 모드)

영웅입지전 모드 '선물·화제 취향 표시'의 배포·소스 저장소입니다. 소스는 MIT-0 으로 공개합니다(LICENSE).

- 교류 → 선물하기 목록에서 상대가 좋아하는 물건의 이름·분류를 분홍색으로 표시합니다.
- 화제 고르기에서 지금 상대에게 효과가 큰(배율 1 넘는) 화제를 같은 분홍색으로 표시합니다.
- 종류 둘: **밸런스판**(이미 알아낸 취향만 표시) · **편의판**('?' 로 가려진 취향까지 표시). 메모장 설정 값만 다릅니다.

## 받기·설치
- 받기: 오른쪽 **Releases** 의 최신 압축(zip)
- 설치 둘 중 하나
  - 압축을 풀고 `밸런스판` 또는 `편의판` 폴더의 `설치.cmd` 더블클릭(게임은 끈 채로). 지우기는 `제거.cmd`.
  - 영웅입지전 모드매니저 창에 압축을 끌어다 놓고 설치 화면에서 종류 고르기. 모드매니저로 설치하면 새 버전을 '업데이트 확인' → '지금 업데이트'로 바로 받습니다.
- 게임 파일은 바꾸지 않습니다. 인터넷 전송 없음. 게임 코드를 고치지(후킹·패치) 않고 화면 글씨 색만 바꿉니다.
- 설명과 사용법: https://gall.dcinside.com/mgallery/board/view/?id=san14&no=78833 (선물 횟수 리셋 아이템 「금란선옥」과 같은 글)

## 소스
- 이 저장소와 압축 안 `개발자용` 폴더에 소스와 빌드 스크립트가 있습니다(Zig 0.14.1 + Python 3).

## 소스와 배포 파일이 같은지 확인하기

이 저장소의 소스로 직접 빌드해 릴리스 압축 안 DLL과 바이트까지 비교할 수 있습니다.
필요한 것: Python 3, Zig 0.14.1 (https://ziglang.org/download/0.14.1/zig-x86_64-windows-0.14.1.zip)

```
python verify_build.py --zig <zig.exe 경로> --zip <받은 릴리스 압축 경로>
```

- 모드 DLL과 입구 파일 4개를 빌드해 압축 안 파일과 비교합니다. 게임 폴더는 건드리지 않습니다.
- 아이템 데이터(JSON, 그림)는 비교 대상이 아닙니다. 압축 안 파일을 직접 볼 수 있습니다.
- 일치한다는 것은 이 소스로 만든 파일이라는 뜻입니다. 소스에 문제가 없다는 뜻은 아니므로 소스 내용은 따로 확인해 주세요.
- 제작자 PC의 서로 다른 폴더에서 일치를 확인했습니다(2026-11-07). 다른 PC에서의 결과는 아직 확인하지 못했습니다.

AI에게 맡긴다면: "이 저장소 소스로 릴리스 압축의 DLL을 다시 빌드해 바이트가 같은지 확인하고, 소스에 위험한 동작이 있는지 검사해 줘."
